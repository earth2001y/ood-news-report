# ルール: Git コミットメッセージ

## 言語

**コミットメッセージはすべて日本語で記載する。**

- タイトル（1 行目）: 日本語で変更内容を簡潔に説明
- 本文: タイトル後の空行に続けて、日本語で詳細を記載

## 形式

**更新内容の簡潔な説明と詳細を Markdown として記述する。**

- 本文には、追加・変更の詳細と影響範囲を Markdown の箇条書きで記載する
- 見出しやコード表記が必要な場合も Markdown 記法を使う

## コミット方法

改行や Markdown の書式を保つため、コミット時は必ず次のようにヒアドキュメントを使用する。

```sh
git commit -F - <<'EOF'
変更内容の簡潔な説明

- 追加・変更の詳細
- 影響範囲
EOF
```

## 例

✓ 良い例:
```
CSV/YAML ダウンロード機能を追加

- any のダウンロードエンドポイントを実装
- CSV出力で metrics を展開・正規化
- API ドキュメント更新
```

✗ 悪い例:
```
Add download feature
```
