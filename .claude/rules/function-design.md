# 設計指針（関数・モジュール）

Python のすべての関数を対象とする。関数の説明に関するルールのみテストコードを
除外する（モジュール docstring はテストを含む全 Python ファイルが対象）。

## 命名と構造

- モジュール外から呼び出す関数には `_` で始まらない名前を付ける。`_` で始まる
  名前は、そのモジュール内だけで使う非公開関数に限定する。
- 関数の処理本体は **80 行以内**に収める。
  - 冒頭の docstring は行数に含めない。
  - 処理中のコメントと空行は行数に含める。
- 制御構造のネストは **3 段以内**に収める。
  - `for` / `while`、`if` / `match`、`try` などを対象とする。
  - 同一の `if` / `elif` / `else`、`try` / `except` は同じ段として数える。

## docstring

- Python ファイルの冒頭に、そのモジュールの責務を説明する**モジュール
  docstring** を記載する。
- テスト以外のすべての関数に、**機能説明**と**その実装にした理由**を記載する。
  - docstring は **Google スタイル**に従う。
  - 機能説明と実装理由はブロックを分離する。
  - 実装理由の先頭には `[実装理由]` と書く。
- 機能説明では「この関数が何をするか（責務）」を、実装理由では「なぜその実装方針を
  採用したか（設計意図・トレードオフ）」を明記する。
